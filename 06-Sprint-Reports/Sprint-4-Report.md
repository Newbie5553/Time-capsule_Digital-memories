## 1. Sprint Goal

The goal of Sprint 4 was to extend the Time Capsule application by introducing memory sharing and title search while maintaining the functionality developed in previous sprints.

## 2. Sprint 4 Deliverables

| User Story | Feature | Development Status |
|---|---|---|
| US-19 | Share an opened time capsule with another registered user | Implemented |
| US-20 | Search time capsules by title | Implemented |

### Additional Features

- Shared With Me dashboard
- Read-only access for recipients
- Recipient permission verification
- Ability for owners to remove sharing access
- Search across owned and shared memories
- Responsive sharing and search interfaces

## 8. Challenges and Limitations

The application is currently intended for local demonstration rather than public deployment.

Known limitations include:
- No public hosting
- No email notifications or password recovery
- No email verification
- No production rate limiting
- Files are not encrypted at rest

These limitations can be considered for future development.
