## 💬 Discussion & Decisions

1. **Locked Capsule Sharing:** Owners should be able to share sealed capsules with registered users, while recipients must not be able to read capsule contents before the scheduled unlock date.

2. **Home Page Navigation:** The Home option must lead directly to the main page, while Create Capsule remains a separate option.

3. **Password Recovery:** A secure Forgot Password option should be provided to help users regain access to their accounts.

4. **Administrator Dashboard:** Administrators should have a dedicated dashboard for managing user accounts, including disabling and restoring users when necessary.

5. **Final Verification:** All updated features must be checked, and project documentation must be completed before final submission.
